### Added

- `p4kx wwise extract --txtp` also writes one vgmstream `.txtp` text file per Wwise event of the
  trigger, next to the sounds. It layers an Event's actions and blend containers, chains sequence
  containers, selects the first child of a random or switch container and carries the loop of each
  sound. An event with a sound that has no whole file is listed instead. P4KX writes the text only;
  it does not run vgmstream.
