### Changed

- CSV: `dcb query`, `dcb fields` and `loc export` write the default CSV like the flat value export,
  with a byte order mark and a leading `'` before a text that a spreadsheet would run as a formula
  (`=`, `+`, `-`, `@`, tab, carriage return); numbers stay unchanged. `--csv-raw` writes the exact
  values. The Query export of the desktop app follows the same rules.
- Field statistics: a Reference now has a distinct count, a Record with too many values adds
  nothing to the counts, and the memory of a count is bounded by the number of threads. A field
  path can be turned into a Query path, and a type name with a backtick is rejected.
