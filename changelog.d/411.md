### Changed

- Vehicle implementations: an item port now tells its types with their sub-types, its display name
  and where each of its values comes from; the Modification's applied `Elem` overrides and the file
  a value was read from can be asked. A patch with several children of one name keeps all of them
  instead of the last one.
- Text XML nested deeper than 128 elements is refused with a typed error by the material, object
  container, `.soc` entity, audio trigger, shop and star map readers, as it already was for vehicle
  implementations and Loadout files.
