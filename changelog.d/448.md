### Changed

- Breaking: the Record XML namespace URI is now
  `https://github.com/greluc/p4k-extractor/record-xml` and the `$id` of the Record JSON schema is
  `https://github.com/greluc/p4k-extractor/schemas/record-json.schema.json`, after the repository
  moved to `greluc/p4k-extractor`. A consumer that checks the old `krt-profit` namespace or schema
  id must switch to the new one. The update check, the About text and the installer link point to
  the new repository.
